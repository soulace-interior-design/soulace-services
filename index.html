登入指引

先找 GitHub 登入按鈕，沒有才用 Google。

  • 你的 GitHub 帳號本身就是用 Google 帳號登入的，所以你實際上只需要記得一組 Google 帳號。
  • 不確定按哪個的時候，先試 GitHub。
